Glissez ici les fichiers ou dossiers de vos matchs

Un dossier par match est l'idéal, mais vous pouvez aussi déposer tous les fichiers en vrac : le dashboard les regroupe automatiquement par match.

Matchs chargés

Les journées sont déduites de l'ordre chronologique de chaque équipe ; corrigez-les si besoin, elles sont mémorisées.

Contrôle des données

Vérifie que chaque match est cohérent : score et buts, quarts d’heure, joueurs et équipe, données physiques, corners, journées. À lancer après chaque import.

Logos et couleurs des équipes

Importez l'image de chaque club (PNG, JPG ou SVG). Les deux pastilles sont la couleur principale et la couleur secondaire du club (cliquez pour les modifier) : la secondaire est utilisée quand deux équipes d'un même graphique ont des couleurs trop proches. Logos et couleurs s'appliquent à tous les utilisateurs.

Fichiers reconnus

Le type de chaque fichier est détecté d'après son contenu, pas son nom.

metadata.json / meta.json : équipes, joueurs, score (au moins l'un des deux est obligatoire) · insight.jsonl : événements Opta + passes, tirs (xG), possessions, conduites → onglet Analyse tactique · physical-summary / physical-splits / physical-minute.jsonl : données physiques → onglet Physique. Le fichier par 5 min (ou par minute) est nécessaire pour filtrer par quart d'heure.
tracking-produced.jsonl (positions brutes, ~400 Mo) n'est pas nécessaire et est ignoré.

Les données restent dans ce navigateur (aucun envoi sur Internet). Pour les transférer vers un autre ordinateur, utilisez « Exporter la base ».
